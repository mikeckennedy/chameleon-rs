## web.TemplateError


A template integration was configured or used incorrectly: no template folder


Usage

``` python
web.TemplateError()
```


configured, a folder that does not exist, a view returning something that is not a model or a response. (Not a template compile error: that is [chameleon_rs.TemplateError](TemplateError.md#chameleon_rs.TemplateError).)
