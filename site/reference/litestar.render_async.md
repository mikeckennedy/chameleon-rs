## litestar.render_async()


[render](flask.render.md#chameleon_rs.flask.render) as a coroutine: the template's [render_async](robyn.render_async.md#chameleon_rs.robyn.render_async), which awaits awaitable


Usage

``` python
litestar.render_async(
    template_file,
    **template_data,
)
```


values where the template uses them (see [PageTemplate.render_async](PageTemplate.render_async.md#chameleon_rs.PageTemplate.render_async)).
