# Markdown spec examples

Test data for `tests/markdown_spec.rs` (the `markdown:` expression type, Phase 11b). Both files
are vendored unmodified; don't edit them.

- `commonmark-0.31.2.txt`: the CommonMark spec, version 0.31.2, from
  https://github.com/commonmark/commonmark-spec (`spec.txt` at tag `0.31.2`). Copyright John
  MacFarlane, licensed under CC BY-SA 4.0.
- `gfm-extensions.txt`: the GitHub Flavored Markdown extension examples, from
  https://github.com/github/cmark-gfm (`test/extensions.txt` on `master`, fetched 2026-10-21).
  Licensed as cmark-gfm's test data (BSD-2-Clause).

They are test data only and are not part of the Python wheel.
